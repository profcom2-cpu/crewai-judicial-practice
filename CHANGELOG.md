# Changelog

## 0.2.0 — 2026-09-10

- Отдельный фронтенд (`web/`) и локальный сервер `practice_crew.webapp`.
- Запуск как приложение: ярлык на рабочем столе → `scripts/launch_desktop.bat` → окно Edge/Chrome `--app`.
- Кнопка «Выход» останавливает сервер. Логи старта/прогона/остановки пишутся в `logs/practice_crew.log`.

## 0.1.0 — 2026-09-10

- Пилотный контур CrewAI «Практика по делу», отдельно от JuristStudio.
- Шесть агентов: извлечение цитат, практика «за», практика «против», сверка цитат, антигаллюцинация, карточки дневника.
- Мозги: Qwen через OpenAI-совместимый API (crewai 1.15, Python 3.12 на D:).
- Логи в `logs/practice_crew.log`, результат в `output/`.
